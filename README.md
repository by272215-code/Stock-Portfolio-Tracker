# 📈 Stock Portfolio Tracker

## Introduction

Stock Portfolio Tracker is a simple Python-based application developed .

The project allows users to calculate the total value of their stock investments by entering stock names and quantities. The program uses a predefined dictionary of stock prices, calculates the investment value for each stock, and displays the total portfolio value. Additionally, the result is saved to a text file for future reference.

This project helped me understand how Python can be used to perform basic financial calculations and manage data using dictionaries, loops, user input, and file handling.

## How It Works

1. The program contains a predefined list of stock prices.
2. The user enters the number of stocks they own.
3. The user provides the stock symbol and quantity.
4. The program calculates the value of each stock investment.
5. All investments are added together to calculate the total portfolio value.
6. The final result is displayed on the screen.
7. The portfolio value is saved in a file named `portfolio.txt`.
